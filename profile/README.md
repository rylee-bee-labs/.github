# 🐝 Rylee-Bee Labs

**A tiny, cozy, mostly-automated game and tools studio.**

Rylee-Bee Labs is where [Rylee](https://github.com/Rylee-Bee) builds small games, the engine under them, and the friendly machinery that keeps it all running. A little hive of AI agents does the busywork: drafting, testing and reviewing. Rylee makes the calls.

### 🍯 How the hive works

- Every change is a pull request; checks run on our own little server; merges happen when they pass.
- Agents never merge their own risky changes. A human taps the button.
- Rules small enough to read, kept honest by checks instead of promises.
